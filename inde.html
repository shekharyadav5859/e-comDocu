Project Overview

E-Commerce is a backend web application developed using Java and Spring Boot. It provides REST APIs to manage products, shopping carts, customer addresses, orders and payments.

The project follows a layered architecture to organize application logic, database operations and REST API endpoints. MySQL is used to store application data.

Live Deployment

The backend application is deployed on Render.

Database: MySQL

Project Features

Product Management

Add, retrieve, update, delete and search products by name, brand, category and price.

Shopping Cart

Add products, increase existing quantity, update quantity and clear the cart.

Address Management

Add, update, retrieve and delete customer addresses. Maintain a default address.

Order Management

Create orders, retrieve user orders, update order status and cancel eligible orders.

Payment Management

Create payment records, retrieve payments and update payment statuses.

Product Search

Search and filter products using name, brand, category and price combinations.

1. Products APIs

Demo: Products API ↗

Base path: /products

Method Endpoint Description
POST/products/saveAdd product
GET/products/Get all products
GET/products/{id}Get product by ID
PUT/products/update/{id}Update product
DELETE/products/delete/{id}Delete product
GET/products/search/name?name={name}Search by name
GET/products/search/brand?brand={brand}Search by brand
GET/products/search/category?category={category}Search by category
GET/products/search/price?min={min}&max={max}Search by price
GET/products/search/name-brand?name={name}&brand={brand}Name and brand
GET/products/search/name-category?name={name}&category={category}Name and category
GET/products/search/brand-category?brand={brand}&category={category}Brand and category
GET/products/search/brand-price?brand={brand}&min={min}&max={max}Brand and price
GET/products/search/name-price?name={name}&min={min}&max={max}Name and price

Create Product Request

{
  "name": "Samsung Galaxy Phone",
  "description": "Android smartphone",
  "price": 25000,
  "stock": 20,
  "brand": "Samsung",
  "imageUrl": "https://example.com/phone.jpg",
  "category": "Electronics",
  "active": true
}

2. Cart APIs

Demo: Cart API ↗

Base path: /cart

MethodEndpointDescription
POST/cart/addAdd product to cart
GET/cart/user/{userId}Get user's cart
PUT/cart/update/{id}?quantity={quantity}Update quantity
DELETE/cart/remove/{id}Remove cart item
DELETE/cart/clear/{userId}Clear cart

Add to Cart Request

{
  "userId": 101,
  "productId": 5,
  "quantity": 2
}

If the same product is added again for the same user, the existing cart quantity is incremented.

4. Order APIs

Demo: Orders API ↗

Base path: /orders

MethodEndpointDescription
POST/orders/placePlace order
GET/orders/Get all orders
GET/orders/{id}Get order by ID
GET/orders/user/{userId}Get user orders
GET/orders/{id}/user/{userId}Get user's specific order
PUT/orders/status/{id}?status={status}Update order status
PUT/orders/payment/{id}?status={status}Update payment status
PUT/orders/cancel/{id}/{userId}Cancel order
DELETE/orders/delete/{id}Delete order

Place Order Request

{
  "userId": 101,
  "addressId": 1,
  "totalAmount": 15000,
  "paymentMethod": "COD"
}

Order Status: PLACED, SHIPPED, DELIVERED, CANCELLED

Current order creation saves basic order details. It does not automatically convert cart items into OrderItem records.

5. Payment APIs

Demo: Payment API ↗

Base path: /payment

MethodEndpointDescription
POST/payment/createCreate payment record
GET/payment/Get all payments
GET/payment/{id}Get payment by ID
GET/payment/user/{userId}Get user payments
GET/payment/order/{orderId}Get payment by order

Create Payment Request

{
  "userId": 101,
  "orderId": 1,
  "amount": 15000,
  "paymentMethod": "UPI"
}

Payment Status: PENDING, SUCCESS, FAILED

Payment APIs currently manage payment records and statuses. No real payment gateway integration has been implemented yet.

Project Architecture

Entity

Defines data models mapped to database tables.

Repository

Provides database operations using Spring Data JPA.

Service

Contains business logic and application operations.

Controller

Exposes REST API endpoints.

Configuration

Manages application and database configuration.

Future Improvements

  • Implement user authentication and authorization.
  • Add role-based access for customers and administrators.
  • Integrate a real payment gateway.
  • Implement OrderItem for multiple products in one order.
  • Connect cart checkout with order creation.
  • Add stock validation and automatic inventory updates.
  • Calculate order totals from actual cart items.
  • Add product reviews.
  • Implement request validation and global exception handling.
  • Add automated unit and integration tests.
  • Publish API documentation using Swagger/OpenAPI.

Important Notes

  • Current APIs use userId, productId and addressId as ID references.
  • Authentication and authorization are not yet implemented.
  • Order creation currently saves basic order details only.
  • Payment status management is not connected to a verified gateway callback.
